# palette
- show color number in hex
- hover a color on palette shows possible OR combinations that results on that color
- click ? to show a modal with a 16x16 grid with all OR color combinations
- alternative color display to favor OR coloring





# tools
- fill area
- draw circle/oval
- draw line
- draw box

# grid
right-click draw transparent pixels
center-click set the color to the selected pixel (except if transparent)

# sprite preview
- hover over a pixel shows its color, pointing out the composition if it's OR-ed
